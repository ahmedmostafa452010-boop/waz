تشغيل شات واوزك (حقيقي ومفتوح لأي حد)

الطريقة 1: استضافة مجانية على Render
1) اعمل حساب على github.com وارفع محتويات المجلد ده (server.js و package.json ومجلد public).
2) ادخل render.com، واضغط New ثم Web Service، واختار الريبو.
3) Build Command: npm install
   Start Command: npm start
4) بعد ما يخلص هيديك لينك. الموقع كله (الصفحة والشات) على اللينك ده.

الطريقة 2: على جهازك للتجربة
npm install
npm start
وافتح http://localhost:3000 في تابين.
